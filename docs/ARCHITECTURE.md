# معمارية JARVIS

## الشكل العام

```
┌──────────────────┐         ┌──────────────────┐
│  أندرويد (Kotlin) │         │  ويندوز (Python)  │
│  Compose + Hilt   │         │  PySide6 + asyncio│
└────────┬─────────┘         └─────────┬────────┘
         │                             │
         │   WebSocket (حضور + مهام)    │
         └──────────────┬──────────────┘
                        │
            ┌───────────▼───────────┐
            │  Cloudflare Worker    │   بلا حالة
            │  CORS، حدّ معدّل، توجيه │
            └───────────┬───────────┘
                        │
         ┌──────────────┴──────────────┐
         │                             │
┌────────▼─────────┐        ┌──────────▼────────┐
│ Hub (Durable Obj)│        │ Guard (DO)        │
│ SQLite لكل مستخدم │        │ حدّ معدّل بالعنوان │
└──────────────────┘        └───────────────────┘
                        │
         ┌──────────────┴──────────────┐
         ▼                             ▼
   OpenRouter (بمفتاح الجهاز)      محرّك النطق
```

## لماذا هذا التقسيم

**الجهاز يفعل ما يستطيع فعله وحده.** فتح تطبيق، رفع الصوت، النقر على عنصر ظاهر — كل هذا محلي بالكامل ولا يمرّ على الشبكة. المواصفة تطلب ذلك صراحة في القسم 18: لا تمرّر أوامر الهاتف البسيطة على خادم بعيد.

**الخادم موجود لشيئين فقط:** ما لا يمكن فعله دون وسيط (ربط الهاتف بالحاسوب عبر الإنترنت)، وما لا يصحّ تكراره على كل جهاز (حدّ المعدّل).

**الحالة لكل مستخدم في كائن واحد.** كل hub هو Durable Object واحد بداخله SQLite. لا قاعدة بيانات مشتركة، ولا استعلام يخلط بيانات مستخدمين. والـ WebSocket يستخدم Hibernation فلا كلفة أثناء الخمول.

## تدفّق أمر واحد

```
نطق أو كتابة
    │
    ▼
تطبيع عربي  (التشكيل، صور الألف، الأرقام الهندية)
    │
    ▼
موجّه النوايا المحلي ──── تطابق واضح ──→ تنفيذ مباشر، صفر رموز
    │
    │ غموض أو تخطيط
    ▼
نموذج عبر OpenRouter  ──→ اختيار أداة ──→ تحقّق ──→ تنفيذ
                                              │
                                   إجراء حسّاس؟ ──→ تأكيد صريح
```

الشرط الذي يحكم هذا كلّه: **لا يُستدعى نموذج لأمر يمكن حسمه بقاعدة.** "افتح يوتيوب" لا تستحقّ طلب شبكة ولا تأخيرًا ولا رموزًا.

## الأمن

| الطبقة | القرار |
|---|---|
| مفتاح OpenRouter | يبقى على الجهاز. يُرسَل في ترويسة ويُمرَّر دون تخزين ولا تسجيل |
| رمز الجهاز | يُخزَّن مُهشَّرًا (SHA-256) في الخادم؛ الموازنة بزمن ثابت |
| على أندرويد | EncryptedSharedPreferences بمفتاح من Android Keystore. وإن تعذّر، يُعلن التطبيق ذلك ولا يكتب نصًّا صريحًا |
| على ويندوز | مخزن بيانات اعتماد النظام عبر `keyring`. وإن غاب، لا يُحفظ شيء ويُعلن ذلك |
| رمز الإقران | ستّ أرقام، مُهشَّر، يُستهلك مرّة واحدة، صالح خمس دقائق، و5 محاولات فاشلة تقفل عشر دقائق |
| النسخ الاحتياطي | الأسرار مستثناة؛ نسخة مستعادة لمفتاح Keystore لا تُقرأ أصلًا |
| السجلّات | كل ما يشبه رمزًا يُحجب قبل الكتابة (`redact`) |
| محتوى خارجي | صفحات الويب والإشعارات ونتائج الأدوات تُعامَل بيانات لا أوامر |
| خدمة الوصول | لا تُمكَّن تلقائيًا، ولا تقرأ حقول كلمات السر، ولا تخفي نشاطها |

## ما يقابل ما بين المنصّتين

ثلاث قطع مكرّرة بين Kotlin وPython بوعي، لأن كل منصّة تحتاجها محليًا:

| القطعة | أندرويد | ويندوز |
|---|---|---|
| الحالات التسع | `core/agent/AssistantState.kt` | `core/state.py` |
| موجّه النوايا | `core/agent/IntentRouter.kt` | `core/intent.py` |
| حجب الأسرار | `core/data/SecureStore.kt` | `core/config.py` |

لكل منهما طقم اختبارات يقابل الآخر حالةً بحالة، فأي تباعد في السلوك يظهر كاختبار فاشل لا كخلاف صامت.

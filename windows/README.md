# LORA على Windows

نزّل حزمة `LORA-Windows-EXE` من بناء Windows الناجح في GitHub Actions.
فك ضغطها ثم فك `LORA-Windows.zip` وشغّل `LORA/LORA.exe` مع إبقاء مجلد `_internal` بجانبه.

- تبدأ لورا بملء الشاشة: خلفية سوداء، دائرة متحركة في الوسط، وإعدادات في الزاوية.
- اضغط الدائرة أو Space لبدء سؤال صوتي واحد. Esc يوقف الاستماع أو الرد، وF11 يبدّل ملء الشاشة، وCtrl+Q يغلق التطبيق.
- ضع مفتاح Groq في الإعدادات؛ يحفظه Windows Credential Manager. الذكاء وصوت Noura يحتاجان اتصالاً وحصة متاحة لدى Groq.
- يتضمن EXE مكتبة Whisper، ويُنزّل نموذج `small` عند أول استعمال (نحو 480 MB).

## بصمة المالك

من الإعدادات سجّل ثلاث عينات، كل واحدة ست ثوانٍ، بجمل مختلفة وفي مكان هادئ.
يُستخرج تمثيل عصبي للمتحدث محلياً عبر WeSpeaker / sherpa-onnx.
تُحفظ البصمة فقط مشفّرة باستخدام DPAPI لحساب Windows الحالي؛ لا يُحفظ التسجيل الخام.
يمكن حذف البصمة أو استبدالها من الإعدادات. إذا فشل الاستبدال تبقى البصمة السابقة.
عند وجود بصمة، يُرفض الصوت غير المطابق أو غير الكافي قبل تحويله إلى نص؛ وعند حذفها تتوقف المطابقة.

**الصوت وحده ليس مصادقة كافية للأوامر الخطرة.** المطابقة تجريبية، لم تُعاير لصوتك أو للعربية، ولا تمنع إعادة تشغيل تسجيل أو استنساخ الصوت. نتيجة التشابه ليست احتمالاً مؤكداً للهوية. حذف الملفات يتطلب دائماً تأكيداً يدوياً للقائمة. من يسيطر على حساب Windows يمكنه إعادة تسجيل البصمة أو فك حمايتها.

## البناء والتحقق

يتحقق `.github/workflows/lora-windows.yml` من الاختبارات، وبصمة SHA256 لنموذج المتحدث، ثم يبني EXE ويشغّله فعلياً مع `--smoke-test` لاختبار استيراد المكتبات وDPAPI وتحميل نموذج المتحدث ورسم الحالات.
يُرفع ZIP كامل مع SHA256 ونتائج الاختبار. بناء فرع `main` فقط ينشر إصداراً تجريبياً قابلاً للتنزيل بعد نجاح كل الفحوص.
توجد التغييرات في [طلب الدمج #2](https://github.com/marccuell839-collab/Sini/pull/2).
اختبارات البناء لا تقيس دقة التعرف على صوت المالك، ولا تختبر الميكروفون الحقيقي أو Groq بمفتاح شخصي.

للتشغيل من المصدر استخدم Python 3.11، ثم `pip install -r requirements-stt.txt`.
نزّل نموذج المتحدث وفق خطوة **Fetch verified local speaker model** في ملف سير البناء وضعه في `windows/models/speaker.onnx`.
شغّل من مجلد `windows` بالأمر `python -m jarvis_win`، وابنِ بالأمر `pyinstaller --noconfirm jarvis.spec`.
